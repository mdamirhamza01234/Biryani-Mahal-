# Biryani Mahal Website

A responsive static website concept for Biryani Mahal, Tilkamanjhi, Bhagalpur.

## Run
Open `index.html` in a browser, or publish this repository with GitHub Pages.

## Important before publishing
- Confirm exact phone number, address, opening hours and current prices with the restaurant.
- Menu values shown are transcribed/representative from customer-provided photos and online listings; multiple menu versions were visible.
- WhatsApp order/enquiry buttons are frontend demonstrations and require the restaurant to confirm the correct WhatsApp number.
- No payment gateway, order database, restaurant admin panel or live order acceptance is connected.
- Food images load from Unsplash and Google Fonts from the internet.
